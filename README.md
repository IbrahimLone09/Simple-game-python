## Rock Paper Scissors(python)
A simple rock paper scissors game built using python.
The user palys against the computer in the terminal,
and the program keeps track of wins until the user quits.

## Features
- Play rock,paper,scissors agianst the computer
- Random computer choices using python's random module
- Score tarcking for both user and computer
- Continous game play using a while loop
- Option to quit anytime by typing Q

## Built with
- python
- random module

## How to Run
1. Make sure python is installed.
2. clone the repository.
- git clone (https://github.com/IbrahimLone09/Simple-game-python.git)
3. Go into the project folder.
- cd simple-game-python
4. Run the program using this command.
- python Rock-paper-scissors.py

## How to play
1. Run the program
2. Type one of the following
- rock
- paper
- scissors
3. The computer will randomly choose its move
4. The program will display the winner of the round 
5. Scores will keep updating
6. Type Q to quit the game
